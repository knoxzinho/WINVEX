WINVEX — Website institucional
================================

Conteúdo:
- index.html: página principal
- styles.css: estilos responsivos
- script.js: menu mobile e FAQ
- assets/: ilustrações SVG e ícones originais

Como visualizar:
1. Extraia o ZIP.
2. Abra index.html em um navegador moderno.

Antes de publicar:
- Edite index.html e substitua https://github.com/ pelo endereço real do repositório WINVEX.
- Atualize o ano/versão quando houver uma nova release.
- Publique a pasta inteira em GitHub Pages, Netlify ou hospedagem estática.

O site utiliza Google Fonts via internet como aprimoramento visual e possui fontes de fallback.
As ilustrações SVG são arquivos locais e não dependem de serviços externos.
