WINVEX — Website institucional
================================

Conteúdo:
- index.html: página principal
- styles.css: estilos responsivos
- script.js: menu mobile e FAQ
- assets/: ilustrações SVG e ícones originais

Como visualizar:
1. Extraia este ZIP do website.
2. Abra index.html em um navegador moderno.

Download e instalação do WINVEX:
- O site aponta para o instalador oficial winvex_0.1.7.exe.
- Página da release: https://github.com/knoxzinho/WINVEX/releases/tag/v0.1.7-alpha
- Download direto: https://github.com/knoxzinho/WINVEX/releases/download/v0.1.7-alpha/winvex_0.1.7.exe
- Para instalar, baixe o EXE e siga as instruções exibidas pelo instalador. Não é necessário extrair um ZIP do aplicativo.

Publicação:
- Publique a pasta inteira em GitHub Pages, Netlify ou hospedagem estática.
- Atualize os links de download e release quando houver uma nova versão.

O site utiliza Google Fonts via internet como aprimoramento visual e possui fontes de fallback.
As ilustrações SVG são arquivos locais e não dependem de serviços externos.
